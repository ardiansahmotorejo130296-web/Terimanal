## 2024-11-20 - Ensuring Minimum Touch Targets for Icons
**Learning:** Applying `.clickable()` directly to a 16dp `Icon` element creates an insufficiently small touch target that fails Android accessibility standards (which require a minimum 48dp touch target). Small icons are very difficult for users to interact with reliably. Additionally, when using `.clickable()` on text or structural items (like an `[X]` text button), it lacks inherent accessibility semantics, making it unclear to screen reader users that it's an actionable button.
**Action:** Always wrap interactive `Icon` elements in an `IconButton` component when applicable, which naturally provides a 48dp minimum touch target. Move the `testTag` and action to the outer `IconButton`. When applying `Modifier.clickable()` to non-button elements (like Text), always include `role = Role.Button` and provide context via `onClickLabel` to ensure screen readers announce the element properly.
