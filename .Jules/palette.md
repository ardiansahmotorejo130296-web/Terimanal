## 2024-11-20 - Adding Accessibility Semantics to Custom Components in Jetpack Compose
**Learning:** Applying `.clickable()` to non-button structural elements like `Box` or `Row` in Jetpack Compose without additional semantics leaves screen reader users with poor context, acting merely as a clickable element without purpose. Additionally, using small `Icon` components (like a 16dp close button) directly instead of `IconButton` violates minimum touch target guidelines (48dp).
**Action:** When adding `.clickable()` to a container, ensure explicit semantics are added using `onClickLabel` and `role = Role.Button` (importing `androidx.compose.ui.semantics.Role`). Always replace standalone functional `Icon` elements with `IconButton` wrappers to guarantee proper touch targets and built-in screen reader support.
