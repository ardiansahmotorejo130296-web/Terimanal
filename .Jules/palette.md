## 2024-11-02 - Ensure explicit accessibility roles and labels for clickables
**Learning:** Found multiple usages of `Modifier.clickable()` on elements such as Text, Row, or Box acting as buttons without explicit `role = Role.Button` or `onClickLabel`. These structural UI elements don't inherently provide screen reader button semantics like a native Button or IconButton would, leaving users of assistive technologies without clear actionable context. Additionally, standard `Icon` elements wrapped in `.clickable()` lack proper touch target sizes (at least 48dp minimum for interactive elements) and screen reader semantics unless replaced by `IconButton` or properly augmented.

**Action:** Replace `Modifier.clickable()` on standard icons with `IconButton` to ensure a 48dp minimum touch target size and proper semantics. For structural elements like Box/Row using `.clickable()`, explicitly add `role = Role.Button` and `onClickLabel` inside the `clickable { ... }` block to enhance accessibility. Ensure any necessary UI test tags are correctly transferred to the wrapper/outer layout when converting `Icon` + `.clickable()` to `IconButton`.
