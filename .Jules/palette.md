## 2024-05-18 - Missing Screen Reader Semantics on Custom Clickables
**Learning:** Found an accessibility issue pattern in Compose UI where custom components like generic `Row` or `Box` items used `.clickable {}` without accompanying semantic properties. This means screen readers don't know the element acts as a button, nor do they get a descriptive action label. Also found small 16dp icons using direct `.clickable` modifiers, failing minimum 48dp touch target size guidelines.
**Action:** When adding `.clickable {}` to non-standard button components, always provide `role = Role.Button` and `onClickLabel`. For small icons, wrap them in an `IconButton` (which inherently provides a 48dp minimum touch target and handles ripples) rather than applying `.clickable` directly to the `Icon`.
