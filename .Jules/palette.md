## 2024-03-24 - Screen Reader Labels for Icon-only Buttons\n**Learning:** Found a missing `contentDescription` for the password visibility toggle icon in `MainActivity.kt`. Providing a state-dependent dynamic label (e.g., 'Show password' / 'Hide password') significantly improves the experience for screen reader users compared to a generic static label or `null`.\n**Action:** Always provide state-aware `contentDescription` properties for toggleable icon buttons in Jetpack Compose UI.
